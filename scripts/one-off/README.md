# One-off scripts

Old maintenance and fix-up scripts that used to sit in the repo root. They are kept for reference only.

- Run them from the **repo root**, e.g. `node scripts/one-off/check-config.js`, so `./server/.env` is found.
- Some of them change or delete production data (for example `wipe_all_billing.js`). Read a script fully before running it.
