# Agent Mode

Agent Mode is the main AI chat at chat.classgrid.in: you ask in plain words, and the agent picks the tools it needs.

## 1. What it is and how to switch modes

-   Agent Mode is the home screen of chat.classgrid.in. It is an agent, not just a chatbot: it can search the web, read
    files, run code, make files and images, publish websites, send email, use connected apps and work in the background.
-   There are three modes: **Agent**, **Project** (code editor on a GitHub repo) and **Studio** (watch the agent work
    in a live browser).
-   To switch, open the menu at the top of the sidebar (the name with the up/down arrows). Under **Switch Mode**, pick
    **Agent**, **Project** or **Studio**. The same menu has a **Docs** link.
-   No special commands are needed. While it works, the agent shows each step (searching, reading a file, running code),
    then replies with text, files, links or answer cards.

## 2. The sidebar

-   **New Chat** starts a fresh chat. **Schedule** opens your reminders. **Library** opens your files.
-   **Search** opens a search box ("Search chat history...") for your old chats.
-   **Pinned** lists chats you pinned. Recent chats are grouped under **Today** and **Previous**.
-   Shared chats (Share Grid) have a small star next to their name.
-   Each chat's menu has **Share**, **Rename**, **Pin chat** / **Unpin chat**, **Move to project** and **Delete**
    (**Leave chat** for a chat someone shared with you).
-   **Move to project** moves the chat into a Project Mode project (an existing one, or a new one you name). It then
    leaves the Agent list and carries on in Project Mode.

## 3. The chat box

-   On a new chat the box says "Ask anything, analyse a file, or schedule a task…".
-   **Enter** sends. **Shift+Enter** adds a new line. The **Expand input** button makes the box bigger.
-   Typing shows formatting: **Ctrl+B** bold, **Ctrl+I** italic, **Ctrl+E** inline code, **Ctrl+K** add a link.
-   **Attach file** (paperclip): up to 6 files per message.
-   **AI Hub** (sliders icon): plugins, skills, settings and **Upgrade**.
-   **Dictate** (mic): speak, and your words are typed into the box to check before sending.
-   **Paste**: pasted files and images are attached. Very long pasted text (over about 600 words) becomes a
    **Pasted text** chip instead of filling the box; up to 2 long texts per message.
-   **Stop generating** stops the current answer.
-   On your own message: **Edit Message** to change it and ask again. On an answer: **Copy response**, **Helpful**,
    **Not helpful** and **Reply to message**.
-   On wide screens, a list icon on the right lists your questions in the chat; click one to jump to it.

### The @ menu

Type **@** in the box to open a quick menu:

-   **Add photos & files** ("Upload from computer")
-   **Add from library** ("Browse and search your files")
-   **Create image** ("Visualize anything")
-   **Web search** ("Find real-time news and info")
-   **Deep research** ("Get a detailed report")
-   Your plugins, such as Gmail, Notion or GitHub

### The model picker

-   It sits next to the mic and starts on **Auto** ("Picks the best model for each message").
-   Groups: **Claude** (Haiku 5.5, Sonnet 5.5, Opus 5.5, Fable 5.1), **DeepSeek** (V4.1 Flash, V4 Pro, V4 Flash) and
    **More models** (GPT-OSS, Kimi, GLM, Qwen, Gemma, Nemotron, Llama, Mistral). New models show a **New** badge.
-   Classgrid can turn any model off. A model that is off is not shown; if it was picked, the chat goes back to Auto.
-   **Claude Fable 5.1** has a lock until your total top-ups reach a set amount; the picker shows how much more is
    needed, and clicking it opens **Upgrade**. Once open, it uses paid credits only.
-   The pick is remembered, and you can change it for any message mid-chat. Every model keeps the same tools.

### The message queue

-   If you send while the agent is still answering, your message waits instead of being lost.
-   A **N queued** button shows above the box; click it to show or hide the list.
-   Queued messages go one at a time, in order, each after the current answer ends.
-   Hover a queued message: **Send** makes it go next (before the others); **Cancel** (X) removes it.

## 4. What the agent can do

-   **Answer cards**: charts, diagrams, flashcards, quizzes, follow-up questions, planners (with **Set reminders**),
    countdowns, timetables, plan cards, live weather, market, map and clock cards, review/score/rating cards,
    copy-ready blocks, action cards and small interactive widgets (polls, calculators, games). Ask by name: "as a chart".
-   **Files and documents**: reads PDF, Word, PowerPoint (with speaker notes), Excel/CSV, text, images, audio (to text)
    and video (speech to text). It remembers files in the chat for follow-ups.
-   **Library**: every upload and every file the AI makes (PDF, Word, Excel, PowerPoint). Search, date filter, sort and
    a storage meter. Reuse a file with **@** > **Add from library**.
-   **Images**: ask, or use **@** > **Create image**. Images are kept in the **AI Hub** under **Images**. Image making
    uses credits and has its own limit. It can add text or a logo on top using the code sandbox.
-   **Web research**: always on, no switch needed. Answers show numbered [n] citations. Paste a link to have it read
    the page; paste a YouTube link to get a summary.
-   **Long tasks**: the agent can pause, wake up later and carry on for up to 48 hours, even with the tab closed.
    Results come on WhatsApp or email with a link to the chat. If credits run out, the task is paused, not deleted.
-   **Incognito**: the ghost **Incognito chat** button at the top right of a new chat. It shows "You're incognito".
    Not saved to history or search, stays in this browser only, and closing it deletes it for good. It still uses
    credits and can't be shared with Share Grid.

## 5. Sharing a chat

-   **Share link** (read-only, public): use **Share** in the chat header (copies the link), or the chat's menu in the
    sidebar > **Share**, which offers **Copy link**, **WhatsApp**, **LinkedIn** and **Email**.
-   The page opens on share.classgrid.in with a "Shared by" line. Readers need no account and can't type or ask the AI.
-   **Email** sends the chat to your own email only. Check for private details before sharing: anyone with the link
    can read it.
-   **Ask Classgrid links**: `https://chat.classgrid.in/?q=YOUR_TEXT` (URL-encoded) opens the chat with that text
    ready in the box. Nothing is sent by itself, and it uses the reader's own credits.

## 6. Grids (in short)

-   Grids is Classgrid's messaging: one-to-one chats and groups with other Classgrid AI users (not WhatsApp).
-   **Polls**: 2 to 10 options, with **Allow Multiple Answers**. **Message Options**: Priority (Normal, High, Urgent),
    **Auto-Delete At** and **Schedule For**. Scheduled messages wait in **Scheduled Messages**.
-   **Share Grid** (icon in the chat header, no label): up to 4 people, counting you, use one AI chat together. Invite
    by email, **Add from Grids** or **Copy invite link**. One person asks at a time; others see "Agent is responding to
    X". Incognito and Project Mode chats can't be shared this way.
-   **AI in Grids**: from your normal AI chat, the agent can summarise a group's recent messages (about the last 1 to 2
    hours), create a poll and read results, draft and post a message, and send a file. It always asks "Should I send
    this to the group?" first, and asks before reading one-to-one chats.
-   The agent can't post into a group on a schedule, and there is no AI bot inside groups.

## 7. FAQ

-   **I sent a message while the agent was busy. Is it lost?** No. It waits in the queue and goes after the current
    answer. Click **Send** on it to make it go next, or **Cancel** to drop it.
-   **A model I used is missing from the picker.** Classgrid has turned it off for now. Pick another model or use Auto.
-   **Does the agent keep working if I close the tab?** Long tasks do, for up to 48 hours, and send the result to you.
-   **Can I get an Incognito chat back?** No. Closing it deletes it. Copy anything you need first.
-   **Share link or Share Grid?** A share link lets anyone read the chat. Share Grid lets up to 4 invited people chat
    and ask the AI together.
