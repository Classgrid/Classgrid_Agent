# Library (phone app)

The Library keeps every file you uploaded and every file Classgrid AI made for you (pictures, PDFs, documents and
more), so you can open, share, download or ask about them in any chat.

## How to open the Library
1. Open the side menu (tap ☰ at the top left).
2. Tap **Library**.
- At the top, the **Storage** card shows how much of your plan's storage is used.
- The first row of chips picks who made the file: **All**, **Uploaded** or **AI-generated** (each with a count).
- The second row picks the type: **All files**, **Images**, **Videos**, **PDFs**, **Documents** or **Audio**.
- Pull the list down to refresh it.

## How to open a file
1. In the Library, tap the file.
2. It opens full screen. Pictures and videos show in place; for a PDF or other file tap **Open PDF** or **Open file**.
3. At the top: the chat icon (ask Classgrid about this file), the share icon (**Share link**) and ⋮ (**Download**,
   **Copy link**, **Delete**). Tap X to close.

## How to search, sort and filter
1. In the Library, tap the round search button at the bottom left.
2. Type in **Search files**. It matches file names.
3. To sort or pick a day, tap the sliders icon at the top right (**Sort and filter**).
4. Under **Sort by** pick **Newest first**, **Oldest first** or **Largest first**.
5. Under **Added on** pick **Any day** or **Pick a day**. A chip **Added** with the day shows; tap it to remove the
   day filter.

## How to upload a file
1. In the Library, tap **Upload** at the bottom.
2. Pick **Camera**, **Photos** or **Files**.
3. A progress bar shows in the Storage card. **File uploaded** shows when it is done.

## How to use a file in a chat
1. Long-press the file (or tap ⋮ on its card).
2. Tap **Ask Classgrid**.
3. Type your question and tap **Ask in a new chat**. A new chat opens with the file attached.

## How to share, copy the link or download
1. Long-press the file (or tap ⋮ on its card).
2. Tap **Share link**, **Copy link** or **Download**. Downloads go to Downloads/Classgrid on the phone.

## How to delete a file
1. Long-press the file (or tap ⋮ on its card), or open it and tap ⋮.
2. Tap **Delete**, then **Delete** in **Delete file?**.
- A file you uploaded is deleted for good.
- An AI-generated file goes to the Trash (the note says **Moved to Trash**) and can be brought back for 30 days.

## How to use the Trash
1. Open the Library (side menu, **Library**).
2. Tap the trash icon at the top right. The **Trash** screen opens.
3. To bring a file back, tap **Restore** next to it. It is back in your Library.
4. To delete everything in the Trash for good, tap the red trash icon at the top right, then **Delete for good**.

## Good to know
- Only AI-generated files go to the Trash. Files in the Trash are deleted for good after 30 days.
- There is no button to delete one Trash file for good. Leave it (it goes after 30 days) or empty the whole Trash.
- Deleting a file frees its storage.
- Settings (gear at the bottom of the side menu) **Storage** shows **Uploaded files**, **AI-generated files** and
  **Trash**; each opens the matching list.
- If an upload is refused because of your plan, the note has an **Upgrade** button.
