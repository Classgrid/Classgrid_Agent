# Projects (phone app)

A project groups chats around one piece of work, usually linked to a GitHub repo. On the phone you can make a
project (name and logo), open it, read its files, chat about it, rename it, change its logo and delete it. Projects
need GitHub connected.

## How to see your projects
1. Open the side menu (tap ☰ at the top left).
2. Tap **Projects**.
3. Each row shows the logo, the name, the GitHub repo (or **No GitHub repo**) and when it was created and last edited.
   Finished Mastero projects are listed under **Mastero projects**, the others under **Projects**.
- Use the **Search projects** box at the top to find one by name or repo.
- Tap the calendar icon at the top right to sort: **Last edited**, **Newest first** or **Oldest first**.
- Tap ⋮ at the top right to choose which kinds show: **Mastero projects** and **Projects** (at least one stays on).
- Pull the list down to refresh it.

## How to create a project
1. Open the side menu (tap ☰), then tap **Projects**.
2. Tap **New project** at the bottom.
3. If GitHub is not connected, the app shows **Connect GitHub**: tap **Open Connectors**, connect GitHub, then come
   back and tap **New project** again.
4. In the **New project** sheet, type the **Project name**.
5. Optional: tap **Add a logo**, pick a picture, move and zoom it in the frame and save it.
6. Tap **Create project**. The new project goes to the top of the list and opens.

## How to open a project
1. Open the side menu (tap ☰), then tap **Projects**.
2. Tap the project. It opens with three tabs: **Chats**, **Files** and **Project**.
- **Chats**: only this project's chats. They never show in the side menu chat list.
- **Files**: the GitHub repo, its branch, the live Vercel app (when there is one) and its files. Tap a folder to go
  in, tap a file to read it. The search icon at the top finds a file anywhere in the repo. In a file you can copy it or
  tap **Open on GitHub**.
- **Project**: GitHub (repo, the branch the agent works on, its open pull request), Vercel, the last commit and the
  history. Tap a row to open it on GitHub or Vercel.

## How to chat inside a project
1. Open the project (side menu, **Projects**, tap the project).
2. Type your question in the **Ask Classgrid** box at the bottom and send it. A new chat starts in this project and
   opens.
3. To open an older project chat, tap it on the **Chats** tab.
4. Long-press a project chat for **Pin** or **Unpin**, **Share**, **Rename** and **Delete**.
- Inside a project chat, the top bar shows the project and the chat name. Tap the project name to go back to the
  project. Tap the chat name to switch to another chat of the same project.

## How to move a chat into a project
1. Open the side menu (tap ☰). Long-press the chat in the list (or on **View all**).
2. Tap **Move to project**. GitHub must be connected; if not, tap **Open Connectors** and connect it first.
3. Tap a project, or tap **New project** to make one and move the chat into it.
4. A note says **Moved to** and the project name. Tap **Open** in it to go to the chat.

## How to rename, change the logo or delete a project
1. Open the project.
2. Tap ⋮ at the top right.
3. Tap **Rename project** (type the new name, save), **Change logo** (or **Add a logo**), or **Delete project**.
4. For delete, confirm with **Delete project**.

## Good to know
- Deleting a project deletes it in Classgrid only. Its code stays on GitHub.
- A moved chat leaves your normal chat list and is on the project's **Chats** tab from then on.
- Only your own chats can be moved. A chat already in another project cannot be moved.
- On the phone the AI reads the project but does not change its code.
- A project that is a folder on a computer shows no files on the phone.

## Not on the phone
- Project instructions and project settings: there is no screen for them in the phone app. Use chat.classgrid.in or
  the desktop app.
- Building or changing the project's code, linking a GitHub repo, Mastero and pushing changes: use chat.classgrid.in
  or the desktop app.
- Moving a chat out of a project: there is no option for it on the phone.
