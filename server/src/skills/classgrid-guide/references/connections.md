# Connections

Everything Classgrid AI connects to, and every way to reach it from outside the chat at chat.classgrid.in.

## 1. Verify your WhatsApp

- Classgrid's official WhatsApp number is **+91 81492 77038**. Save it as a contact, for example "Classgrid AI".
- Steps: send "Hi" to that number on WhatsApp first (so WhatsApp can deliver the code) → on the **Verify WhatsApp** screen pick the country code and enter your number → tap **Send OTP** → type the 6-digit code that arrives in the same WhatsApp chat.
- The code works for 10 minutes. A new code can be asked for after 60 seconds.
- Verifying unlocks: WhatsApp calls, results and files sent to WhatsApp, WhatsApp reminders, and long tasks that wait for your WhatsApp reply.
- One number, one account: calls and messages are only taken from a number verified on exactly one Classgrid account.

## 2. WhatsApp messages

- Texting the number does **not** start a new task. With no task open, the Classgrid help bot answers (it helps with setup, like verifying).
- New tasks start from a WhatsApp call or an email to agent@classgrid.in.
- While a task is open, your WhatsApp texts, photos and PDFs go to that task. You get a short "got it" style reply and the agent carries on with them.
- Results arrive as normal WhatsApp messages. PDFs, images, audio and video arrive as real files. A finished task ends with "✅ Task completed." and a link to the chat.
- From any chat you can ask: "Send this PDF to my WhatsApp" or "When the report is ready, send it to me on WhatsApp."
- There is a weekly limit on WhatsApp messages from Classgrid AI (set by Classgrid). Credits are used as normal.

## 3. Call Classgrid AI on WhatsApp

- Open WhatsApp, find **+91 81492 77038** and tap the voice call button. A normal phone call does not reach the AI, and there is no call button inside chat.classgrid.in.
- The AI answers: "Hi {first name}, this is Classgrid AI. What can I do for you?" Speak in English. You can interrupt it.
- Quick questions are answered live, using the full agent and your connected apps (Gmail, Calendar, Drive, Notion, GitHub, Vercel and more). If an answer takes longer than about 90 seconds, it is sent to your WhatsApp instead.
- Bigger jobs are saved as a task and done after you hang up. Coding or website work runs in Project Mode; other work (reports, emails, research) runs in a normal Agent chat.
- After the call: "Got it. Classgrid AI is working on it now. I'll send you the result here when it's done." The result and a chat link come on WhatsApp.
- No task saved: you get a short recap titled **Your call with Classgrid AI**. If the call drops, any request already made is kept and worked on.
- Limits: up to 15 minutes per call (the AI is told when time is almost up), a daily limit on answered calls per number (set by Classgrid), and credits are needed. The AI never calls you.
- Unverified number: "This WhatsApp number is not linked to a Classgrid account…". Out of credits: "You're out of Classgrid AI credits right now…".

## 4. Email the agent

- Send an email to **agent@classgrid.in** from the same email address you sign in with. Mail from any other address is not linked to you and starts nothing.
- The inbox is checked about every 45 seconds. You get a short automatic reply by email, and the work runs as a background task.
- Attach any files the agent needs (up to 25 MB each). The agent reads them like files uploaded in chat.
- An email task gets its own Project Mode project, named after the email's subject. Find its chat there.
- If a task is already open for you, a new email (or WhatsApp message) adds to that task instead of starting over.
- The agent can also send emails for you from any Agent mode chat: "Make this a PDF and email it to name@example.com." These come from agent@classgrid.in and can carry files. To send from your own address, connect **Gmail** or **Microsoft Outlook** and ask it to use that.

## 5. Schedules and reminders

- Make one by asking in chat: "Remind me every Monday at 7 am to plan my week." You can also type in the **Schedule a task...** box on the **Scheduled** page, which opens a new chat with your text.
- The reminder text is written when the schedule is made. At the set time that same text is sent. The AI does not run again, so a schedule can't send fresh news, prices or reports.
- Repeat options: one time, daily, weekly, or chosen weekdays. A repeat runs for up to 90 days (30 days if no end date is given).
- Where it arrives: email always (your account email); WhatsApp too if your number is verified and you asked for it. Over the weekly WhatsApp limit, only the email goes.
- The **Scheduled** page lists your schedules with **All**, **Pending** and **Completed** filters, a status (**Pending**, **Completed**, **Failed**, **Cancelled**), a repeat label like "Repeats daily · until 16 Oct", a copy-link button and delete.
- Ask in chat to change a schedule's time, title or text, or to delete it.
- Schedules go only to you. They can't post into Grids (use **Schedule For** in the message options there) and can't watch a site or inbox.

## 6. Long background tasks

- Work from a WhatsApp call or an email always runs as a background task. A chat can also become one when the agent needs to wait.
- When it must wait, the agent pauses itself and sets a wake-up: a time, your next WhatsApp reply, or both. Nothing runs and no credits are used while it waits.
- Your WhatsApp reply wakes it at once; set times are checked every few minutes. It picks up with the full chat so far.
- A task can work for up to 48 hours. If unfinished: "Sorry, Classgrid AI could not finish your task in 48 hours, so it has stopped." with a link to what was done. If it was only waiting for your reply, it closes with a short recap and "🔒 Task closed."
- A failed run is tried again about 5 minutes later. After 5 runs in a row with no progress, it tells you it is stuck and waits for your reply.
- Credits run out: "⏸️ Your AI tokens ran out, so I paused your task…". It continues by itself when credits come back, or sooner if you top up.
- A server restart does not lose the task; it carries on by itself.
- Incognito chats can't run as long tasks (they are not saved).

## 7. Plugins (apps the agent works in)

- Open: tap the sliders icon in the message box → **AI Hub** → **Plugins** tab (**Plugins & Integrations**) → tap an app → **Connect** → sign in and allow access.
- Each plugin card has **Try asking the AI** examples.
- Use it by asking in plain words, or type **@** in the message box and pick the app (handy when you have Gmail and Outlook both connected).
- Apps: Gmail, Google Calendar, Google Drive, Google Classroom, Google Forms, Google Meet, Microsoft Outlook, Microsoft Teams, Zoom, Slack, Notion, GitHub, Vercel, Sanity CMS, Canva, YouTube, Spotify, Facebook Pages, Instagram Business, WhatsApp Business.
- The agent acts as you: Gmail sends from your address, Slack posts as you, Drive uploads go to your Drive. Ask for a draft first before anything is sent or posted.
- Each plugin does a focused set of things. For example: Calendar can list and create events but not move or cancel them; Vercel can deploy but can't roll back or show build logs; Outlook can't delete or move emails; Instagram posts need an image; Spotify playback needs Premium and an open Spotify app.
- **WhatsApp Business** needs your own Meta app details (Phone Number ID, Permanent Access Token, Webhook Verify Token) and sends from your business number, not the Classgrid number.
- Disconnect: **AI Hub** → **Plugins** → tap the app → **Disconnect**. Things already done in the app stay there.
- The **Connected apps** tab in the AI Hub is the other direction: outside apps like Claude, Cursor or ChatGPT that you allowed to use your Classgrid account. **Remove** cuts one off straight away.

## 8. GitHub (needed for Project Mode)

- First time in Project Mode: **Connect GitHub to use Project Mode** → **Connect GitHub** → sign in. If the link expires, click **Reconnect GitHub**.
- Install the Classgrid GitHub app on the repos you want: **Install app** on the Projects page, pick the account and repos on GitHub.
- New project: **New project** → **Project name** → **Create** → **Link a GitHub repo** (private repos work), or **Enter project without a repo**.
- No repo yet: click **Ask Agent to create repo**. Repos the agent makes are private unless you ask otherwise.
- A project opens the latest commit of the default branch (or the open Classgrid pull request's branch). Your changes go back to GitHub as a pull request on a classgrid/… branch. Ask "push straight to main" to push to the default branch with your own GitHub account instead; some accounts always push straight to main.

## 9. Vercel (put a Project Mode site live)

- Connect the **Vercel** plugin in the AI Hub. Project Mode has no deploy button of its own.
- Then ask the agent: create a Vercel project, add environment variables (keep secret keys there, not in code), deploy a branch as a preview, or deploy to production.
- Good flow: push your change → "Deploy that branch to Vercel as a preview and give me the link" → check it → merge or deploy to production.
- Roll back a deploy or read build logs in your Vercel dashboard.

## 10. Publish a website on Classgrid

- In an Agent mode chat, ask the agent to build a site, then "Publish it as my-name". It goes live at **my-name.sites.classgrid.in**.
- Site names: 3 to 40 lowercase letters, numbers and dashes. The first person to publish a name owns it.
- To change the site, keep chatting in the same chat and ask it to publish again to the same name.
- Published sites are public. Don't put passwords, ID numbers or home addresses on them.
- Not available in Project Mode chats or in tasks from a WhatsApp call or email. Use Vercel there.

## 11. FAQ

- **I texted the WhatsApp number and only got a help message.** No task was open. Call the number or email agent@classgrid.in to start one.
- **Why didn't the AI pick up my call?** The number must be verified on exactly one account, the call must be a WhatsApp voice call, and you need credits and calls left for the day.
- **Will my daily reminder have new information each day?** No. The same text, written when you made it, is sent each time.
- **Do I need to keep the browser open for a long task?** No. It runs on Classgrid's side and messages you when done.
- **Can I publish to sites.classgrid.in from Project Mode?** No. Use the Vercel plugin, or publish from an Agent mode chat.
