# Classgrid

Classgrid AI in your code editor. Chat with the Classgrid Agent in the side panel, and let it work on the project you have open: read and change files, run commands in the terminal, and remember what matters about your work.

Works in VS Code, Cursor, Windsurf and VSCodium, and comes built into Classgrid Code.

## What you can do

- **Chat beside your code.** The Agent opens in the right side panel. Ask it to explain a file, fix an error or build a feature.
- **Let it do the work.** It reads and edits files in your open folder and runs commands in your terminal.
- **Point at code.** It sees the file you have open, your cursor and your selection, and the problems your editor shows, so "fix this" just works.
- **Jump to the change.** Files the Agent mentions open right in your editor, at the right lines.
- **Keep your history.** Your chats and the Agent's memory notes follow your Classgrid account, on the web and in the desktop app too.
- **Search past chats** with `Ctrl+K` (`Cmd+K` on Mac).

## Sign in

1. Open the Classgrid panel on the right, or run **Classgrid: Sign in** from the Command Palette.
2. Your browser opens the Classgrid sign-in page. Sign in with Google, GitHub or your email, or create a free account.
3. Your browser sends you back to the editor, and you're signed in.

If your browser doesn't open the editor, copy the code it shows and run **Classgrid: Paste sign-in code**.

## Commands

| Command | What it does |
|---|---|
| Classgrid: Sign in | Sign in with your Classgrid account in the browser |
| Classgrid: Paste sign-in code | Finish signing in with the code from the browser |
| Classgrid: Sign out | Sign out of Classgrid in this editor |
| Classgrid: Show the Agent | Open the Agent panel |
| Classgrid: Open Classgrid | Open Classgrid (Agent, Studio, Projects) in a tab |
| Classgrid: Search Chat History | Find a past chat (`Ctrl+K`) |
| Classgrid: Settings | Classgrid settings |

## Requirements

- A free Classgrid account.
- Windows is fully supported. The Agent's terminal and file tools work on the computer where your editor runs.
