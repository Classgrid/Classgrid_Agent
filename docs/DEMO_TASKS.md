# Demo tasks for Classgrid AI (WhatsApp call + background work)

Real tasks that show what Classgrid AI can do. Use them for launches, LinkedIn posts and demos.

---

## 1. Design Thinking FA2 website (the big one)

Say this on a WhatsApp call:

> "Hello, I have a website submission for my Design Thinking FA2 exam in two days. First, go through my Google Classroom, find the rubric for this FA2, and read it along with any important attachments. If it's not in Classroom, check my Gmail for it.
>
> Then research some real problems people are facing right now, and send me a few problem ideas on WhatsApp. I'll pick one.
>
> After I pick, build a real website for it using React with Vite, and give the project a name that fits the problem. Make real pages: a homepage, a contact page, and a login page. For the contact form use Formspree; I'll send you the Formspree link on WhatsApp. For login use Supabase; I'll email you the Supabase keys from my own email, so check my email for them.
>
> I'll also send you a full detailed prompt for the website on WhatsApp. Then build the complete website."

**What it shows:**
- Reading Google Classroom and Gmail.
- Research.
- Asking on WhatsApp and waiting for the user's pick.
- Taking keys from WhatsApp and email.
- Building and shipping a full React website.

This is something ChatGPT or other assistants can't do live.

## 1b. Internship portfolio and applications (the bigger one)

Say this on a WhatsApp call:

> "Hello, I want to apply for software internships this week and I need your help from start to finish.
>
> First, find my resume. Look in my Google Drive, and if it's not there, search my Gmail for it. Read it fully and send me a short summary on WhatsApp of my skills, projects and education, so I can check you got it right.
>
> Then look at my GitHub account and pick my three best projects for a portfolio. Send me the three on WhatsApp with one line about each, and I'll confirm or swap one.
>
> Then research five software internships that are open right now in India, in Pune or remote, with the company, the role, the stipend if it's shown, the deadline and the link. Send them to me on WhatsApp. I'll pick two.
>
> After that, make a new project for my portfolio website and suggest three names for it so I can choose. Build it with React and Vite. It needs a home page about me, a projects page with my three projects, a resume page, a contact page and a login page for a small guestbook. For the contact form use Formspree; I'll send you the Formspree link on WhatsApp. For the guestbook login use Supabase; I'll email you the Supabase URL and anon key at agent@classgrid.in, so read your email for them. Keep the keys in an env file, not in the code.
>
> Then write a short cover letter for each of the two internships I picked, matched to that company and role and to my resume. Make each one a PDF and send both to me on WhatsApp so I can check them. Only after I say okay, email both PDFs to me with a ready email I can send to each company.
>
> If anything is missing or unclear at any step, ask me on WhatsApp and wait for my answer. When everything is done, push the portfolio to a GitHub repo with a README, and send me the repo link on WhatsApp with a short list of everything you did. Don't host the website anywhere."

**What it shows:**
- Finding and reading a file from Google Drive or Gmail.
- Reading the user's GitHub and picking the best projects.
- Research with real links and deadlines, then the user's pick.
- Asking on WhatsApp and waiting at several steps (summary check, projects, internships, name, PDFs).
- A React + Vite site in Project Mode, with Formspree from WhatsApp and Supabase keys from its own inbox (agent@classgrid.in).
- Two tailored cover letter PDFs, sent only after the user's okay.
- A README, a repo link and a final report.
