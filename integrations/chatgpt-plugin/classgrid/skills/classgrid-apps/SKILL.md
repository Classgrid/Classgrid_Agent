---
name: classgrid-apps
description: Use the apps the user has connected to Classgrid (Gmail and Google Workspace, Microsoft, Notion, Slack, GitHub, Zoom, YouTube).
---

Use the Classgrid connector tools only for apps the user has already connected inside Classgrid. Only those
apps appear as tools; if an app is missing, tell the user to connect it in Classgrid first, then try again.

- Using these tools needs the "Use your connected apps" permission. If a tool says the user did not allow this
  action (insufficient scope), tell them they can grant it by reconnecting Classgrid and ticking that box.
- Before anything that sends, posts, creates, changes or deletes something in another app (an email, a message,
  a file, an event), show what will happen and act only after the user agrees.
- Do not read more than the user asked for, and keep summaries short.
- File links must be https addresses.

Never ask for passwords or tokens for these apps in the chat.
