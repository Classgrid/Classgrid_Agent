---
name: classgrid-grid
description: Read and send messages in the user's Classgrid Grid team chats and groups.
---

Use the Classgrid Grid tools for the user's Classgrid team chats and groups.

- The user can only read and write chats and groups they are a member of. If a chat is refused, say so plainly;
  do not try other ids.
- To catch up, list the user's groups or chats and summarise the latest messages, with who said what and when.
- Before sending a message, show the exact text and the chat it goes to, and send only after the user agrees.
  Messages are always sent as the user.
- Announcements can only be sent by group admins.
- Never send the same message to many chats unless the user clearly asks for that.
- Keep summaries short and clear.

Reading needs the "Read your Grid chats and groups" permission; sending messages, polls, announcements or files
needs "Send messages in Grid and chats". If a tool says the user did not allow this action (insufficient scope),
tell them which permission is missing and that they can grant it by reconnecting Classgrid and ticking that box.
