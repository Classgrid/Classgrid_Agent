Help the user get started with Classgrid.

1. If the Classgrid tools are not connected yet, ask the user to connect their Classgrid account. A Classgrid
   sign-in page opens (if they are not signed in yet), then a Classgrid permission screen. Each permission is a
   checkbox: "Read your profile" is always on; reading schedules, Grid chats, projects and live docs starts ticked;
   reading their Classgrid AI chat history and their skills and memory starts unticked, and so does anything that
   can make changes (schedules, Grid messages, docs, pages, connected apps). They tick what they want and click Allow.
2. Explain in one or two short sentences what they can do: read their Classgrid projects and the code in each
   project's GitHub repo, search their Classgrid AI chats (if they allowed it), read and write live docs, publish
   pages, see and create schedules and reminders, read and send messages in their Grid chats and groups, and use
   apps they have already connected to Classgrid (such as Gmail, Drive or Notion) if they allowed it.
3. Tell them they can remove access at any time in Classgrid under AI Plugins > Connected apps. To give more
   permissions later, they can disconnect and connect again, then tick the extra boxes.
4. Offer one example to try, such as "List my Classgrid projects" or "Show my Classgrid schedules for this week".

Never ask for a Classgrid password, code or token in the chat.
