name: classgrid-setup
description: Help the user connect their Classgrid account and explain what the Classgrid plugin can do.
---

Help the user get started with Classgrid.

1. If the Classgrid tools are not connected yet, ask the user to connect their Classgrid account. A Classgrid
   sign-in page opens (if they are not signed in yet), then a Classgrid permission screen. Each permission is a
   checkbox: "Read your profile" is always on; the read permissions (schedules, Grid chats) start ticked; anything
   that can make changes (creating or editing schedules, sending Grid messages, using their connected apps) starts
   unticked. They tick what they want and click Allow.
2. Explain in one or two short sentences what they can do: see and create schedules and reminders, read and send
   messages in the Grid chats and groups they belong to, look up their own profile, and use apps they have already
   connected to Classgrid (such as Gmail, Drive or Notion) if they allowed it.
3. Tell them they can remove access at any time in Classgrid under AI Plugins > Connected apps. To give more
   permissions later, they can disconnect and connect again, then tick the extra boxes.
4. Offer one example to try, such as "Show my Classgrid schedules for this week".

Never ask for a Classgrid password, code or token in the chat.
