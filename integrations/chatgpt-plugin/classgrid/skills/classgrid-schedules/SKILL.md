---
name: classgrid-schedules
description: Show, create, change or delete the user's Classgrid schedules and reminders.
---

Use the Classgrid schedule tools for anything about the user's Classgrid schedules or reminders.

- To show schedules, list them and give each one's title, date and time in the user's time zone.
- To create a reminder, make sure you know what it is about and when (date and time). Ask one short question if
  either is missing. For repeating reminders ("every day", "every Monday"), create one repeating schedule, not
  many single ones.
- Before deleting a schedule, confirm which one with the user.
- After any change, confirm what was saved in one short line.

Only act when the user asks. Reading schedules needs the "Read your schedules" permission; creating, editing or
deleting them needs "Create, edit and delete your schedules". If a tool says the user did not allow this action
(insufficient scope), tell them which permission is missing and that they can grant it by reconnecting Classgrid
and ticking that box on the Classgrid permission screen.
